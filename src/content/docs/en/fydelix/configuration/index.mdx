Fidelity X is configured mainly through the graphical [Fidelity X Configurator](https://app.flightng.com) — just open it in a WebSerial-capable browser (Chrome / Edge), no install required.

---

## Connecting

1. Connect the flight controller to your computer with a USB cable
2. Open [app.flightng.com](https://app.flightng.com) in your browser
3. Click **Connect** in the top right, pick the matching serial device in the picker and authorize it

Once connected, the navigation bar reveals the configuration pages below.

---

## Configurator Pages at a Glance

| Page | Purpose |
|------|---------|
| Status | Attitude display, board orientation editing, IMU calibration, parameter backup/restore (YAML), reboot to DFU |
| Motors | Motor map, pole pairs, direction, CG bias, motor testing |
| Receiver | Stick preview, channel mapping, polarity, deadzone, AUX function binding |
| OSD | OSD layout editor, element toggles, output port selection |
| Presets | Apply official preset configurations |
| Configuration | Rate curves, filters, PID tuning |
| Debug | Live IMU data capture |
| Storage | Blackbox storage overview, logging mode, USB export, format |
| CLI | Command-line terminal (advanced) |

Firmware flashing happens on the **Home** page while disconnected — see [Firmware Flashing](/en/fydelix/flashing/).

---

## The "Configuration" Page

The configurator's **Configuration** page has three sections:

| Section | Contents | Parameters |
|---------|----------|------------|
| Rates | Per-axis rate curve type + RC Rate / Super Rate / Expo | `rate_curve_type`, `rate_curve_roll/pitch/yaw` |
| Filters | RPM filter strength | `rpm_filter_strength` |
| PIDs | Angle loop, rate loop, D-term filter, TPA/TDA | `angle_pid_small/big`, `rate_pid_roll/pitch/yaw`, `dterm_lpf_cutoff` |

:::note[Saving settings]
After editing in the configurator, click **Save** to write to the flight controller's flash. **Reset** clears all parameters back to defaults.
:::

## CLI Method (Advanced)

If you prefer the command line, you can read/write parameters on the **CLI** page with the `config` command:

```bash
config get rate_pid_roll
config set dterm_lpf_cutoff 90
config save
```

See the [CLI Reference](/en/fydelix/cli-reference/) for the full command set.
