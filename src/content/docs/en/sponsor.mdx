## Completed Milestones

### Fidelity X Project 🆕

After three years of incubation, Fidelity X has completed:

- [x] Real-time operating system architecture
- [x] Multi-IMU support (BMI270, ICM42688P, LSM6DSV16X, LSM6DSK320X)
- [x] Advanced filtering system
- [x] Comprehensive safety protection system
- [x] OSD support (MSP DisplayPort / onboard MAX7456)
- [x] Blackbox logging
- [x] Multi-RC protocol support (CRSF, SBUS, SBUS_FAST)
- [x] Multi-board support
- [x] Multi-MCU platform support (AT32 / STM32G4 / STM32F4 / Unicmicro)

### atbetaflight Project

- [x] Betaflight 4.3.1 port
- [x] F435 FC support (LQFP64)
- [x] F435 FC support (QFN48)
- [x] iNavFlight port
- [x] Sensor driver optimization

## Silicon Ecosystem Partner

<div style="display: flex; align-items: center; gap: 2rem; flex-wrap: wrap; margin: 2rem 0;">
  <img src="/assets/images/artery.png" width="220" alt="ARTERY Technology" style="max-width: 100%; height: auto;" />

The development of the AT32-based flight controllers received substantial support from **ARTERY Technology**, the silicon vendor behind the AT32 family. ARTERY dedicated senior engineers to provide one-on-one technical support — spanning BSP bring-up, low-level peripheral drivers, hardware fault diagnosis, and timing and stability tuning — and worked through multiple rounds of joint debugging alongside us.

This close chip-to-firmware collaboration helped the AT32 platform reach its full potential in flight control. We extend our sincere thanks to ARTERY for their technical expertise and ongoing support.
