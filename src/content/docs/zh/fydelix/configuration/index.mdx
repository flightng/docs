Fidelity X 的配置主要通过图形化的 [Fidelity X Configurator](https://app.flightng.com) 完成——用支持 WebSerial 的浏览器（Chrome / Edge）打开即可，无需安装。

---

## 连接飞控

1. 用 USB 线连接飞控与电脑
2. 浏览器打开 [app.flightng.com](https://app.flightng.com)
3. 点击右上角 **连接（Connect）**，在弹出的串口选择框中选择对应设备并授权

连接成功后，导航栏会出现下列配置页面。

---

## 配置器页面一览

| 页面 | 作用 |
|------|------|
| 状态（Status） | 姿态显示、飞控朝向编辑、IMU 校准、参数备份/恢复（YAML）、重启进 DFU |
| 电机（Motors） | 电机映射、极对数、转向、CG 偏置、电机测试 |
| 接收机（Receiver） | 摇杆预览、通道映射、极性、死区、AUX 功能绑定 |
| OSD | OSD 布局编辑、元素开关、输出端口选择 |
| 预设（Presets） | 应用官方预设配置 |
| 配置（Configuration） | 速率曲线、滤波、PID 调参 |
| 调试（Debug） | 实时 IMU 数据采集 |
| 日志存储（Storage） | 黑盒存储概览、记录模式、USB 导出、格式化 |
| 命令行（CLI） | 命令行终端（高级） |

固件刷写则在断开状态下的 **首页（Home）** 进行，详见 [固件烧录](/zh/fydelix/flashing/)。

---

## 「配置」页详解

调参器的 **配置（Configuration）** 页分为三个部分：

| 部分 | 内容 | 对应参数 |
|------|------|----------|
| Rates（速率） | 每轴速率曲线类型 + RC Rate / Super Rate / Expo | `rate_curve_type`、`rate_curve_roll/pitch/yaw` |
| Filters（滤波） | RPM 滤波强度 | `rpm_filter_strength` |
| PIDs | 角度环、角速度环、D 项滤波、TPA/TDA | `angle_pid_small/big`、`rate_pid_roll/pitch/yaw`、`dterm_lpf_cutoff` |

:::note[保存设置]
在配置器中修改后，点击页面的 **保存（Save）** 才会写入飞控 Flash。`重置（Reset）` 会清除所有参数恢复默认。
:::

## 命令行方式（高级）

偏好命令行的用户也可以在 **CLI** 页用 `config` 命令读写参数：

```bash
config get rate_pid_roll
config set dterm_lpf_cutoff 90
config save
```

完整命令见 [CLI 命令参考](/zh/fydelix/cli-reference/)。
