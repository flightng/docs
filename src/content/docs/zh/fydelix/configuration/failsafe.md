title: 安全系统 (Failsafe)
description: Fidelity X 内置安全保护机制
---

Fidelity X 内置完善的安全保护机制，确保飞行安全。

:::note[始终启用]
RC 信号丢失保护与解锁检测由固件强制执行，无法关闭。
:::

---

## 保护功能

| 功能 | 说明 |
|------|------|
| RC 信号丢失保护 | 检测遥控信号丢失并执行两阶段保护 |
| 电池电压监控 | 实时监控并在 OSD 显示警告 |
| 解锁条件检测 | 满足条件后才允许解锁 |
| 油门低保护 | 防止意外解锁后高油门 |

---

## RC 信号丢失保护

固件采用固定的两阶段保护策略（动作由固件内置，不可自定义）：

| 阶段 | 触发 | 动作 |
|------|------|------|
| 第一阶段 | 检测到信号丢失 | **保持最后有效的控制信号**，给链路恢复的机会 |
| 第二阶段 | 信号持续丢失 | **强制 Disarm**（停转电机），防止失控漂飞 |

:::caution[没有自动降落]
Fidelity X 的失控第二阶段是直接停机（Disarm），**不提供"自动降落/受控下降"**。请确保在开阔安全的环境飞行，并设置好图传/遥控的失联提醒。
:::

---

## 电池电压监控

固件按 **每节电芯电压** 监控电池，电压阈值为硬编码、并根据自动识别的电芯节数换算：

| 状态 | 阈值（每节） | 4S 等效 |
|------|--------------|---------|
| 警告 | 3.5V / 节 | 14.0V |
| 危险 | 3.3V / 节 | 13.2V |

:::caution[电池监控仅警告]
电池电压监控**只在 OSD 上显示警告**，不会主动停机或降落。请结合飞行习惯及时返航。
:::

## 解锁条件

解锁前系统会检查：

- [x] 传感器状态正常
- [x] 加速度计已校准
- [x] 油门处于最低位
- [x] RC 信号有效

所有条件满足后才能解锁。

---

## 可调参数

失控系统对外暴露的可调参数只有一个：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `fs_throttle_low_time` | 2000 | 油门低保护计时（ms） |

其余阶段动作（第一阶段保持信号、第二阶段停机）与电池阈值均由固件内置，无需也无法自定义。

```bash
config get fs_throttle_low_time
config set fs_throttle_low_time 2000
config save
```

---

## 飞行前检查

1. 在调参器 **接收机（Receiver）** 页确认 RC 通道正常
2. 测试失控响应：解锁前关闭遥控器，确认飞控判定为信号丢失
3. 确认信号恢复后能重新获得控制
4. 检查 OSD 电压显示是否正常
