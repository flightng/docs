## 实时架构

不是优化，是重新设计。

传统固件在单一循环中依次处理任务，任何一个环节的延迟都会拖累整体性能。Fidelity X 构建于 **RT-Thread** 实时操作系统之上，把关键工作拆分为独立、带优先级的线程并行运行：

- **陀螺仪采样与滤波** 独立成线
- **姿态解算与控制混控** 拥有专属优先级
- **电机输出（IMU/DShot）** 永远准时
- **遥控接收** 与 **安全监控（Failsafe）** 各自独立

**结果**：确定性的响应时间，无论系统负载如何。

## 滤波系统

信号处理，决定飞行品质。

### 陀螺仪与 D 项滤波

消费级 MEMS 陀螺仪并不完美——电机振动、机架谐振、传感器噪声，都会污染原始数据。Fidelity X 的滤波链路精确识别这些干扰，保留真实的姿态变化。

PID 的微分项天生对噪声敏感，因此 D 项配有专用低通滤波器（参数 `dterm_lpf_cutoff`，默认 90Hz），在抑制高频噪声的同时把相位畸变降到最低。

**效果**：电机保持冷静，响应依然锐利。

### RPM 滤波

借助 **双向 DShot** 回传的实时转速，固件可精准定位电机谐波并将其消除。滤波强度通过 `rpm_filter_strength` 调整（Roll/Pitch/Yaw 各一档）。

:::note[滤波器的可调范围]
大部分滤波参数已为你调校好。日常使用通常只需关注 `dterm_lpf_cutoff` 与 `rpm_filter_strength`，无需深入调整其他底层滤波参数。
:::

## 安全系统

**始终运行。**

### RC 信号丢失保护

两阶段智能响应：

| 阶段 | 触发 | 响应 |
|------|------|------|
| 第一阶段 | 检测到信号丢失 | 保持最后有效的控制信号，给链路恢复的机会 |
| 第二阶段 | 信号持续丢失 | 强制 Disarm（停转电机），防止失控漂飞 |

### 电池电压监控

实时监控电池电压，并在 OSD 上显示警告。

:::caution[电池监控仅警告]
电池电压监控**只在 OSD 显示警告**，不会主动停机或降落。请结合自己的飞行习惯及时返航。
:::

### 解锁检测

起飞前，系统会自动验证传感器状态、油门位置与遥控信号有效性，条件不满足将拒绝解锁。

## 控制系统

### 双环 PID

- **外环（Angle）**：角度控制，用于自稳模式，参数 `angle_pid_small` / `angle_pid_big`
- **内环（Rate）**：角速度控制，核心响应来源，参数 `rate_pid_roll` / `rate_pid_pitch` / `rate_pid_yaw`

### 速率曲线

三种风格，一种选择权——你的。

| 曲线 | 适合 |
|------|------|
| Betaflight Rate | 从 Betaflight 迁移的飞手 |
| Actual Rate | 喜欢直观设置的飞手 |
| FlightOne Rate | 从 FalcoX / FlightOne 迁移的飞手 |

每个轴（Roll / Pitch / Yaw）都可以独立选择曲线类型。混搭，由你。

## 显示与记录

### OSD

通过 **MSP DisplayPort** 协议驱动数字图传；部分飞控还板载 **MAX7456 / AT7456E** 模拟 OSD 芯片。屏幕上显示的，是你需要的信息：

🔋 电池电压　⏱️ 飞行时间　📶 信号强度　✈️ 飞行模式

### Blackbox

飞行数据，完整保存。

采用基于 **Gorilla 算法** 的时序压缩格式（浮点 XOR 编码 + 整数 delta 编码），在有限空间内记录更长时间的飞行数据。日志可存储于**板载 SPI Flash（NOR / NAND）** 或 **SD 卡**，并支持通过 **USB 大容量存储（MSC）** 模式直接导出到电脑，供事后深度分析。

## 协议支持

### 遥控协议

| 协议 | 备注 |
|------|------|
| CRSF | 推荐，最低延迟，支持遥测 |
| SBUS | 广泛兼容 |
| SBUS_FAST | 高速 SBUS（200k） |

### 电机协议

**DShot150 / DShot300 / DShot600，支持双向 DShot。**

指令传输与转速回传都在微秒级完成。闭环设计让 RPM 滤波成为可能——精准追踪电机谐波，实时消除。
